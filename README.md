## M/S EQ(マスターFXラック・v11.47〜)
FX タブのラックに **M/S EQ** があります(WIDTH の次)。ステレオを **Mid(中央)** と **Side(左右の広がり)** に分けて別々に EQ します。MID は LOW・MID・FREQ・HIGH、SIDE は LOW CUT・LOW・MID・FREQ・HIGH(ゲインは ±12 dB)。ONにして初期値のままなら音は変わりません。SIDE LOW CUT を上げると低い音が真ん中にまとまります。MONO にたたむと Side は消えて Mid だけが残ります。標準のフィルターだけで作っていて、AudioWorklet が使えない端末でも動きます。旧い保存データは OFF で読まれ、並び順も自動で補われます。

## 計測(MIX のマスター・v11.45〜)
MIX 画面のストリップの下に計測の行(`.lmrow`)があります。**測るだけで音は変えません**。曲を**流しながら**測ります(アプリ内に書き出し・オフライン解析はありません)。
- **METER 切替**: PEAK/RMS(クレスト付き)・VU(近似。0 VU の基準は −18/−14/−20 dBFS から選べる目安)・LUFS(M=400ms・S=3秒・I=流し始め/RESET からの全体。LRA・TP(近似)・PLR)。
- **相関バー**(+1=同じ・0=無関係・−1=逆相)・**バランス**(L−R の dB)・**モノ差**(モノにたたむと何 LU 下がるか)。常に表示。
- **目標の目安**: 放送向け −23・配信向け −14 など(`SD.LOUD.TARGETS`。出典と取得日は `docs/LM_targets.md`。配信先の規定は変わることがあります)。I(なければ S)との差と TP 上限の目安を表示。
- **RESET**: I・LRA・TP の積み上げを消します。計測の設定は保存しません。
- **レッスンの目標(v11.46〜)**: `mt` 目標の `m` に `lufsM`/`lufsS`/`lufsI`/`tp`/`plr`/`corr`/`bal`/`mdiff` を指定できます(マスターのみ)。ステップの開始から測り直し、`hold` 秒つづけて範囲に入ると達成です。AudioWorklet が使えない端末では達成になりません。
- **注意**: LUFS・TP・VU は近似の計算で、他の測定器との一致は未確認です(測定器ごとに少し違うことがあります)。AudioWorklet が使えない端末では LUFS・VU・相関は「—」で、PEAK/RMS は従来どおり動きます。
