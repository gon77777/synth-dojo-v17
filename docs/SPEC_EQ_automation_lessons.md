# 仕様書: EQのオートメーション・レッスン(基礎から飛び道具まで)

対象アプリ: シンセ道場(v8.4-step5 時点のコードを読んで作成)
前提: `SPEC_オートメーション拡張_インサート対応.md` の基盤(`iEq*` がレーンの対象)は実装済み。
目的: トラックのEQ4(`iEq*`)を、レーンで時間的に動かすレッスンを、基礎→応用→飛び道具の順にそろえる。

> 補足: 依頼文の「EQのサイドチェイン」は、「EQのオートメーション」の意味と解釈した。EQ自体に側鎖入力はない。「音に反応してEQが動く」ダイナミックEQは、au65(説明のみ)で扱い済み。

## 1. 方針

1. **既存のレッスンは変えない**(CM・EQ・FQ・VO・MX など)。理由: `au` ステップを足すと、auレッスン扱いになる副作用があるため(§0)。
2. **新規レッスンを、新コース `au10`「AU-J EQのオートメーション」に足す**。コース名は仮。登録は `SD.CATS.push({id:'au10',synth:'analog',chapter:'auto',name:'AU-J EQのオートメーション'})`。目次での並び順(`au10` が `au2` の前に来ないか)を、E1で確認する。
3. **au70(EQのGAINを動かす)を、`au10` に移す**(`cat:'au8'`→`'au10'` だけの変更。IDは変えない)。
4. **動かすのは連続つまみだけ**(ONと切り替えは動かさない)。
5. **1レッスン = 動かす対象を1〜2つに絞る**。1つのレッスンで、EQ・COMP・FXを混ぜない。
6. 数値は目安にとどめる。つまみの値は `F()` で書き、「何Hzが正解」とは書かない。
7. 聴き比べ(`cmp`)は、「動かさない」を必ず入れる。音量が変わるものは `cmp.g`(音量補正)を測る(E5)。
8. 音の確認ができない環境で書くため、**各レッスンの完了条件に、手元の端末での確認を入れる**。

## 2. レッスン一覧

ID は `au72` から。au70 は既存(移動のみ)。★=新規。

### 基礎(帯域を1つずつ動かす)

| ID | タイトル | 動かすつまみ | 覚えること |
|---|---|---|---|
| ★au72 | ローカット(HPF)を上げる | `iEqHpf` | 低域を抜く動き。ビルドアップの定番(au30 のトラック版) |
| ★au73 | ハイカット(LPF)で閉じる・開く | `iEqLpf` | 高域を削って「こもる→開く」。フィルターとの違い |
| au70 | EQのGAINを動かす(既存) | `iEqB2g` `iEqB2f` | ベルを持ち上げる・中心を動かす |
| ★au74 | 棚(LOW・HIGH)を動かす | `iEqLg` `iEqHg` | 低域の厚み・高域の明るさを、場面で変える |
| ★au75 | ベルの幅(Q)を動かす | `iEqB2q` | 広いベル=自然、狭いベル=クセが出る |

### 応用(場面とミックスの中で使う)

| ID | タイトル | 動かすつまみ | 覚えること |
|---|---|---|---|
| ★au76 | 引き算の掃引で、濁りを探す | `iEqB2f`(GAINは−) | 削りながら掃引して、耳で問題の帯域を見つける(eq06 の動く版) |
| ★au77 | 場面でEQを切り替える | `iEqHpf` `iEqHg` `iEqB1g` を階段で | イントロ→サビで、EQの設定を一度に変える |
| ★au78 | ドロップ前に低域を抜く | `iEqHpf`(複数トラック) | ブレイクで低域を抜き、ドロップで一気に戻す |
| ★au79 | 2つのトラックで、帯域を入れ替える | T2の `iEqLg` ↓ / T3の `iEqLg` ↑ | 補完EQ(eq08)を、時間で入れ替える |

### 飛び道具

| ID | タイトル | 動かすつまみ | 覚えること |
|---|---|---|---|
| ★au80 | ワウ・フィルター(ベルの掃引) | `iEqB2f`(高Q・高GAIN)をサインで | 狭いベルを往復させる、ワウの音 |
| ★au81 | 電話の声(帯域を絞る・広げる) | `iEqHpf` ↑ と `iEqLpf` ↓ を同時に | 両側から挟んで、細い音にする→戻す |
| ★au82 | ランダムなEQ(階段で飛ばす) | `iEqB1f` `iEqB2f` を階段で | サンプル&ホールド風に、帯域を飛び飛びに動かす |
| ★au83 | EQの仕上げ演習(場面転換) | `iEqHpf` `iEqLpf` `iEqHg` | 学んだレーンを組み合わせて、8小節の場面転換を作る |

※ ダイナミックEQ・マルチバンドは、au65(説明のみ)にあるため、新規は作らない。au83 のコラムで案内するだけにする。

## 3. 各レッスンの設計

### 共通テンプレート(各レッスン 6〜7ステップ)
1. **聴く**: 動かす前の音を聴く(`clr:'au', bars:4`)。
2. **手で動かす**: MIXタブで、つまみを手で動かして、音を確かめる(`tab:'mix'`)。
3. **レーンを作る**: AUTOタブで、対象のレーンを作る(`au:[{id,trk,has:1}]`)。
4. **描く**: 値を指定してレーンを描く(`au:[{… at, mono}]` と `ref` を必ず対にする)。
5. **(応用)もう1つ動かす / 形を変える**
6. **聴き比べる**: `cmp` に3つ(動かす・別の形・動かさない)。
7. **使われどころ**: `col`(500字以内。実在の事例・年号は書かない)。

音源の基本: T1 キック(`kick`)・T2 ベース(`bass`)・T3 ハット(`hat`)。EQを掛けるトラックは `o.mx:{eq:{iEqOn:1,…}}` で最初からONにする。

### 基礎

**au72 ローカット(HPF)を上げる**
- 音源: T1 キック・T2 ベース・T3 ハット。EQはT2に ON。
- レーン: T2 `iEqHpf`(`trk:1`)。先頭 `F('iEqHpf',20)` → 4小節目 `F('iEqHpf',800)`、右上がり・指数(`'E'`)。
- `ref`: `[[0,20,'E'],[L4,800]]`(au30 の `HP` と同じ形)。
- 聴き比べ: HPFを上げる / 階段で上げる(`stp`) / 動かさない。
- コラム案: 低域を抜くと、ベースが細くなり、キックと分かれる。ビルドアップで低域を抜く使い方。

**au73 ハイカット(LPF)で閉じる・開く**
- 音源: T2 ベース(のこぎり波。倍音が多いもの)+ T1 キック。T2のEQに ON、`iEqLpf` は 20000Hz から始める。
- レーン: `iEqLpf`。先頭 20000Hz → 2小節目 800Hz へ下がり、保って、4小節目で戻す(のこぎり型でなく台形)。
- 注意: `au` 目標は `hold` を使う(au38 の書き方)。
- 聴き比べ: 閉じる / 開く(逆) / 動かさない。
- コラム案: シンセの LPF(フィルターのカットオフ)との違い。EQのLPFは、音色を作る前の素材をそのまま削る。

**au70 EQのGAINを動かす(既存)**
- 移動のみ(`cat:'au10'`)。内容は変えない。au74・au75 の前提になる。

**au74 棚(LOW・HIGH)を動かす**
- 音源: T1 キック・T2 ベース・T3 ハット。T2に `iEqLg`、T3に `iEqHg` を動かす。
- レーン: T2 `iEqLg`: 0 → +9dB(4小節・右上がり)。T3 `iEqHg`: −9 → +9dB(三角・回数1)。
- 聴き比べ: LOW ↑ / HIGH 往復 / 動かさない。
- 補足: `iEqLf`・`iEqHf` は固定のまま(ここでは動かさない)。
- コラム案: 棚は「ここから先を全部」持ち上げる。ベルより自然で、広い範囲の明るさ・厚みを変えるのに向く。

**au75 ベルの幅(Q)を動かす**
- 音源: T2 ベース。`iEqB2g` は +9dB に固定、`iEqB2f` は 800Hz。
- レーン: `iEqB2q`: 先頭 0.5 → 4小節目 6(右上がり・対数カーブ)。広い持ち上げから、狭く尖った持ち上げへ。
- 聴き比べ: Qを上げる / Qを下げる(逆) / 動かさない。
- コラム案: Qが小さいと広く自然に、大きいと狭くクセが出る。狭いブーストは、問題の帯域を探すときにも使う。

### 応用

**au76 引き算の掃引で、濁りを探す**
- 音源: T2 ベース(濁りのあるパッド的なもの。コード系の音源が使えるか実装時に確認)。
- 手順: BELL2 を `−9dB`・Q `3` に固定し、`iEqB2f` を 400→4000Hz の右上がりで動かす。「どこで音がスッキリするか」を耳で探す。
- 目標: `iEqB2f` のレーン(`ref` あり)。GAINは動かさない。
- 聴き比べ: 掃引する / 低域だけ掃引 / 動かさない。
- コラム案: 引き算のEQで、問題の帯域を探す手順(eq06・fq の内容と対応)。DAWでは、掃引はプラグインのつまみを手で回して行う。

**au77 場面でEQを切り替える**
- 音源: T1〜T3。T3 ハットのEQを、イントロ(暗い)→サビ(明るい)で切り替える。
- レーン(階段 `stp`): T3 `iEqHpf`(300→20Hz)・`iEqHg`(−6→+6dB)を、2小節目で同時に切り替える。
- 聴き比べ: 階段で切り替える / なめらかに変える / 動かさない。
- コラム案: 場面ごとにEQを変えると、サビが広く聞こえる。シーン(`play.sc`)とレーンの使い分けにも触れる。

**au78 ドロップ前に低域を抜く**
- 音源: T1 キック・T2 ベース・T3 ハット。T2・T3 の `iEqHpf` を動かす。
- レーン: 3小節目まで 20Hz のまま、4小節目で 600Hz へ急に上げ(崖)、ドロップ(次のループ頭)で 20Hz へ戻す。
- 目標: `hold` と `mono` を併用(au21・au38 に近い書き方)。
- 聴き比べ: 抜く(崖) / 少しずつ抜く / 動かさない。

**au79 2つのトラックで、帯域を入れ替える**
- 音源: T2 ベース・T3 コード(またはパッド)。
- レーン: T2 `iEqLg`: 0 → −9dB。T3 `iEqLg`: −9 → 0dB。反対向きの2本。
- 聴き比べ: 入れ替える / 同時に上げる(ぶつかる) / 動かさない。
- コラム案: 帯域を譲り合う補完EQ(eq08)を、時間で入れ替える。

### 飛び道具

**au80 ワウ・フィルター(ベルの掃引)**
- 音源: T2 ベース(のこぎり波)。`iEqB2g` は +12dB、`iEqB2q` は 5 に固定。
- レーン: `iEqB2f` を、サインで回数 4(4小節で4往復)。400→3000Hz。
- 聴き比べ: サイン / 三角 / のこぎり(形で音が変わる)。
- 注意: 高Qの掃引は、ジッパーノイズが出やすい(E0 で確認)。ひどければ Q を下げる。

**au81 電話の声(帯域を絞る・広げる)**
- 音源: T2 ベース(またはコード)。
- レーン: `iEqHpf`: 20→500Hz(上がる)、`iEqLpf`: 20000→3000Hz(下がる)。両側から挟む。2小節で絞り、2小節で戻す。
- 聴き比べ: 両方動かす / HPFだけ / 動かさない。

**au82 ランダムなEQ(階段で飛ばす)**
- 音源: T2 ベース。`iEqB1g` は +9dB に固定。
- レーン: `iEqB1f` を、階段(`stp`)で8段、ランダムな順に(au17 の書き方)。
- 聴き比べ: ランダム / 上昇の階段 / 動かさない。

**au83 EQの仕上げ演習(場面転換)**
- 音源: T1〜T3。8小節(`bars:8`)。
- 課題: 前半4小節を暗く(HPF↑・HF↓)、後半を明るく(HPF↓・HF↑)。**自分で描いて、条件を満たす**(2本以上のレーンで)。
- 目標: `rng`(範囲)で採点する形(最終ステップ。au の総合演習の形式を踏襲)。
- コラム: au65(ダイナミックEQ・マルチバンド)へ案内。

## 4. 作業ステップ

各ステップは、「作業」「完了条件」「止めどころ」。

### E0: 音の検証(go / no-go)
- **作業**: 開発用に、T2のEQで、(a) `iEqB2f` を高Q(5以上)・高GAINでサイン掃引、(b) `iEqHpf` を急に上げる(崖)、を再生する。
- **確認**: プチプチ音の有無・CPU・`mode:'trk'` と `mode:'seq'` のどちらでトラックのEQのレーンが使えるか。
- **完了条件**: 結果を README に記録。問題があれば、au80 の Q を下げる、または au80 を後回しにする。
- **止めどころ**: 問題が解決しないなら、au80・au82 だけ保留して、他に進む。

### E1: コースの登録・au70 の移動
- **作業**: `SD.CATS.push(au10)`・au70 の `cat` 変更・目次での並び順の確認・`test/validate.js` の実行。
- **完了条件**: 全テスト通過・au70 が au10 に出る。

### E2: 基礎5本(au72・au73・au74・au75 と au70)
- **作業**: 1本ずつ書いて、そのつど `validate.js`(`ref` が目標を満たすこと)。
- **完了条件**: 各レッスンが、手元の端末で、手順どおりに進められる。

### E3: 応用4本(au76〜au79)
- **作業**: 音源の選定(コード系・パッド系の確認)。階段・崖・反対向きのレーン。
- **完了条件**: 同上。

### E4: 飛び道具4本(au80〜au83)
- **作業**: E0 の結果を反映。au83 は、`rng` 採点の目標を設計。
- **完了条件**: 同上。

### E5: 聴き比べの音量補正
- **作業**: `cmp` の音量差を測り、`cmp.g` を付ける(`tools/cm-cal.js` と同じ流儀で、`tools/au-eq-cal.js` を新規に用意)。測定は node-web-audio-api のある環境で。
- **完了条件**: 比較のあいだの推定音量差が、既存の基準(1dB以内)に収まる。収まらない比較は、本文で「音量が変わる」と断る。

### E6: 仕上げ
- README に `v8.6`(仮)の行・検証結果。`docs/HISTORY.md` に追記。`www/sw.js` のキャッシュ名を更新。
- 用語集: 必要なら「棚(シェルフ)」「Q」「ワウ」を `SD.TERMS` に追加(既存にあるか確認)。

## 6. リスクと対策

| リスク | 対策 |
|---|---|
| 高Q・高速掃引で、プチプチ音が出る | E0 で確認。au80 の Q を下げる・更新間隔を伸ばす(旧仕様のステップ0の対処候補と同じ) |
| 目次でau10が並び順どおりに出ない | E1 で確認。必要なら、コースの並べ順を明示する |
| `mode:'seq'` でトラックのEQが使えない | 原則 `mode:'trk'` で作る(§0) |
| EQがOFFのとき、レーンが効かない | 各レッスンの開始時に `iEqOn:1` を敷く。AUTOタブには既存の「効きません」ヒントがある |
| 高域・中域の音源が足りない | 音源の選定を E3 の最初に行う。足りなければ、`SD.DRUMBY` の高域系や、パッチ指定(`o.p`)で作る |
| 聴き比べの音量差で、「効果」と「音量」が混ざる | E5 で `cmp.g` を測る。測れないあいだは、本文で断る |
| 本文の数値が、正解のように読める | 方針6のとおり、`F()` の値か、目安として書く |
