# 仕様書: オカルト・オーディオコース(OC)

対象アプリ: シンセ道場 v16.0(`synth-dojo-v16_0.zip`)
位置づけ: 「家に電柱を立てる」「ケーブルの向き」などの、オーディオの不思議な話(俗説・文化)を、**面白く読みつつ、自分の耳で確かめる方法を身につける**独立コース。読み物と聞き比べの体験で組む。MR(マスタリング)コースの書き方・検査をそのまま踏襲する。

> 数値(周波数・つまみ値・範囲)はすべて「案」。耳と測定で確かめて直す前提(§7)。レッスン本文は未作成。

---

## 0. 目的と立ち位置

- ねらいは「オカルトを笑う」ことでも「信じさせる」ことでもない。**①言われていることを知る ②理屈があるか、測れるかを仕分ける ③思い込みに左右されない確かめ方を知る**の3つ。
- 結論を押しつけず、「理屈のある部分」「確かめにくい部分」を、どちらも本文に書く。
- 既存の作法(音量を揃えて比べる=`lm11`・`mr02`)の応用編として位置づける。既存コースに新機能は要らない(§5 の任意項目を除く)。

---

## 1. 方針

1. **1本1テーマ**。手順は 3〜5 ステップ。本文は 150 字以内・年号なし。
2. **仕分けの3区分**を全レッスンで使う: 【理屈あり】(測れる・仕組みが説明できる)/【確かめにくい】(差が小さい・人による)/【思い込みの影響が大きい】(聞く前の期待で変わる)。1つの話題を、3区分のどれか(または複数)に分けて書く。
3. **断定しない**。「効かない」とも「効く」とも書かない。「測定では差が出にくい」「理屈はこう」「確かめ方はこう」と書く。「必ず」「絶対」「すべて」は使わない。
4. **笑わない・脅さない・急がせない**。信じている人を否定しない。音量は小さめで、こまめに休む(`COL` の定型文を踏襲)。
5. **特定の機材名・メーカー名・商品名・人名・団体名・規格名は書かない**(MR・MX と同じ)。「高価なケーブル」「専用の電源」のように一般名で書く。
6. **安全(必須)**: 電気に関する回は、**電気工事は資格のある業者に任せる・自分で配線をいじらない・コンセントやブレーカーの中に触れない**を本文に入れる(oc02 は必須・oc08 も)。「やってみよう」と勧めるのは、アプリの中で完結する体験だけにする。
7. **お金を使わせない**。購入を勧める文は書かない。「確かめてから」「借りて試す」など、出費を急がせない立場で書く。
8. **近似は本文に書く**: アプリ内の体験は、実際の現象の**近似(まねたもの)**であること(例: ハムは低い音で近似・部屋の共振は EQ の山で近似)を、体験の回の本文に必ず書く。
9. **聞き比べ(`cmp`)の音量差は 1 dB 以内**(音量差そのものを見せる回〔oc03・oc07〕は例外で、その旨を本文に書く)。
10. 判定は耳→数値の順。数値(`mt`)で合格にする回は少なく、**`quiz`(聞き比べの番号を答える形式)と、読み物の理解確認**が中心。

## 3. レッスン仕様

表記: **学ぶこと** / **言われていること** / **理屈と限界** / **使う** / **流れ** / **合格** / **注意**。

### oc01 不思議な話の読み方〔read〕
- 学ぶこと: オーディオの不思議な話を、【理屈あり】【確かめにくい】【思い込みの影響が大きい】に仕分ける考え方。
- 流れ: ①不思議な話はたくさんある(ケーブル・電源・置き物など)②3つの区分 ③まず同じ音を2回聴く(次項)④このコースの進み方。
- 使う: `cmp` に**まったく同じ**音を2つ(A・B)。「違いを探そう」と書く。
- 合格: `quiz` は無し(同一音の聞き比べで答えのある問いにできないため)。確認は本文の最後の問いかけのみ。
- 注意: 同じ音と明かしたうえで、「違って聞こえることもある。それは普通のこと」と書く。用語: 期待バイアス(新)。

### oc02 家に電柱を立てる(電源の話)〔recipe〕
- 言われていること: 家の専用の柱から電気を引くと、音がきれいになる。
- 理屈と限界: 家庭の電気には、ほかの機器が出すノイズが乗ることがある(【理屈あり】。測れる)。ただし、聞こえるかは機器の作りや環境で大きく変わり、費用も大きい(【確かめにくい】)。
- 使う: ハムの近似=低い音(50Hz/60Hz 付近)の、ごく小さい持続音を別トラックで重ねる(`noiseLvl` と低い音のサイン波。§4)。ヒス=ノイズ音を小さく重ねる。
- 流れ: ①電気にノイズが乗る仕組み(読み物)②ノイズなし/ありの聞き比べ(音量は揃える)③ノイズの量を変えて、どこから聞こえるか確かめる ④確かめにくい理由(音楽のレベルが高いと隠れる)。
- 合格: `quiz`(ノイズが入っているのは)+「聞こえ始める量」の自己確認(本文)。
- 注意(必須): **電気工事は資格のある業者に任せる。自分で配線をいじらない。** ハムは低い音で近似していると書く。費用が大きい旨も書く(勧めない)。用語: 電源ノイズ(新)・ハム(新)。

### oc03 ケーブルの向きと値段〔recipe〕
- 言われていること: ケーブルに向きがある/高いケーブルは音が良い。
- 理屈と限界: 短い普通のケーブルでは、測定で差が出にくいと言われる(【確かめにくい】)。名前や値段を知ると、聞こえ方が変わる(【思い込みの影響が大きい】)。
- 使う: A・B・C の3つの音。**1つだけ**ごく小さな違い(+0.6 dB の音量差など。§7 O-4)を入れ、残り2つは同一。ラベル(「高級」「普通」「新品」など一般名)を付けた順と、本当の違いの位置を別にする。
- 流れ: ①ラベル付きで聴く ②どれが違うか選ぶ(`quiz`)③答えを見て、ラベルや期待で選んでいなかったかを振り返る ④ブラインドの意味。
- 合格: `quiz`(違うのは A・B・C のどれ)。正解・不正解どちらでも、本文で責めない。
- 注意: 「違いが分からなくてもよい」と書く。実際のケーブルの優劣を断定しない。音量差が混ざると「大きい方が良く聞こえる」ので、そこも種明かしで触れる。用語: ブラインドテスト(新)。

### oc04 置き物とスピーカー台(振動・共振)〔recipe〕
- 言われていること: 石や脚(インシュレーター)を置くと、音が締まる。
- 理屈と限界: 台や部屋が特定の低い音に共鳴することは実際にある(【理屈あり】)。置き物の効果は、機器・床・部屋で変わり、差は小さい(【確かめにくい】)。
- 使う: 部屋の共振の近似=MASTER EQ(または トラックEQ)の BELL を 80〜120 Hz 付近に +4〜+6 dB・高めの Q で盛る。OFF と ON を聞き比べ(音量は揃える)。
- 流れ: ①共振とは(既存の `xe_reson` を引く)②共振あり/なしの聞き比べ ③EQ で山を下げると濁りが減る ④置き物で直したくなる前に、置き場所・音量・EQ を見る。
- 合格: `f`(BELL を -3〜0 dB に戻す)+`quiz`。
- 注意: 近似であると書く。「効く/効かない」を断定しない。用語: 共振は既存語を再利用。

### oc05 聞こえない高い音(ハイレゾの話)〔recipe〕
- 言われていること: 20kHz を超える高い音まで出すと、音が良くなる。
- 理屈と限界: 人が聞こえる上限は年齢や個人で違い、だいたい 15〜20kHz(【確かめにくい】)。上の帯域が、聞こえる音に間接的に影響するかは、意見が分かれる。
- 使う: トラックの `iEqLpf`(LPF)を 20000(OFF)/ 18000 / 16000 / 12000 Hz に。`mr26` のロッシー風モニターの近似も併用できる。
- 流れ: ①聞こえる上限は人それぞれ ②OFF と 16000Hz を聞き比べ(音量は揃える)③12000Hz で、はっきり差が出る ④自分の耳で、どこから分かるかを確かめる。
- 合格: `quiz`(いちばん高域が無いのは)。
- 注意: 上限の数値は目安で個人差が大きいと書く。大きな音で高い音を聴かない(耳を守る)旨を入れる。用語: 可聴域(新)。

### oc06 真空管やテープの「温かみ」〔recipe〕
- 言われていること: 古い機材のひずみが、温かい音を作る。
- 理屈と限界: 軽いひずみは倍音を足し、音色を変える(【理屈あり】。測れる)。「温かい」と感じるかは好みで、音量が少し上がると良く聞こえやすい(【思い込みの影響が大きい】)。
- 使う: FX の SATURATOR(`sa`)を少し(つまみ名は実装時に確認。§7 O-5)。ON/OFF の**音量を揃えた**聞き比べ(`g` を実測)。
- 流れ: ①ひずみ=倍音が増える ②音量を揃えずに聴く(`quiz`: 大きく聞こえるのは)③揃えて聴く ④少しなら好み、多いと濁る。
- 合格: `quiz` 2問(「大きく聞こえるのは」「倍音が多いのは」)。
- 注意: 機材名は書かない(「古い機材」「ひずみの道具」)。用語: 倍音ひずみは既存語があれば再利用。

### oc07 慣らし運転・聴き疲れ・音量の錯覚〔recipe〕
- 言われていること: 機器は使い込むと音が良くなる/長く聴くと音が変わる。
- 理屈と限界: 耳と脳は、聴いているうちに慣れ・疲れる(【理屈あり】)。小さい音では低音と高音が聞こえにくく、大きくすると豊かに聞こえる(音量による聞こえ方の変化)。機器の変化は小さく、確かめにくい(【確かめにくい】)。
- 使う: 小さめ/大きめの聞き比べ(**音量は揃えない**。例外の回)。休憩(タイマー風の本文の指示)。
- 流れ: ①小さい音と大きい音 ②大きい方が「良い音」に聞こえやすい ③休んでから、もう一度聴く ④比べるときは音量を揃える(`lm11`)。
- 合格: `quiz`(低音が豊かに聞こえるのは)。
- 注意: 長く大きな音で聴き続けない。休憩を促す。「機器の慣らし」は確かめにくいと書き、断定しない。用語: 聴き疲れ(新)。

### oc08 総合: 自分で確かめる実験を組む〔diag〕
- 学ぶこと: ここまでの考え方を使い、気になる話を**自分で確かめる手順**を組む(音量を揃える・人に切り替えてもらう・順番を変える・回数を重ねる)。
- 使う: これまでの体験の聞き比べ。任意で ABX 機能(§5 OC-F)。
- 流れ: ①話題を選ぶ(例: 電源ノイズ・高域カット)②何を比べるか1つに絞る ③音量を揃える ④ブラインドの手順 ⑤回数と、偶然で当たる確率。
- 合格: 診断問題(`quiz`: 手順のおかしい所を当てる)+記録の `kit`(自分の確かめ手順を保存)。
- 注意: 「正解は1つではない」「分からなくてもよい」と書く。結果を他人に押しつけない旨も入れる。用語: プラシーボ(新)。

## 4. 体験素材の作り方(既存機能だけで作る)

| 体験 | 作り方 | 近似の限界(本文に書く) |
|---|---|---|
| ハム | 低い音(50/60Hz 付近)の持続音を、別トラックでごく小さく重ねる | 実際のハムは倍音を含み、機器で違う |
| ヒス | `noiseLvl` のノイズ音を小さく重ねる | 実際のヒスは周波数の偏りが違う |
| 同一音の聞き比べ | 同じ `tm`・設定を A・B に割り当てる(ラベルだけ変える) | — |
| 小さな差(oc03) | A・B・C の1つだけ `g` や `tVol` を ±0.6 dB 程度ずらす | 実際のケーブルの差ではない |
| 部屋の共振 | BELL を 80〜120Hz・+4〜+6 dB・高め Q | 実際の部屋はもっと複雑 |
| 高域のカット | `iEqLpf` を段階で変える | 実際の機器の高域特性とは別 |
| ひずみ | SATURATOR(`sa`)を少し | 実際の真空管・テープの音とは別 |
| 音量差 | `cmp` に `g` を付けない(例外と明記) | — |

- ハム・ヒス用のトラックは、`tk` に**補助トラック**として足す(土台の5トラック+1)。リスナーが「ノイズなし/あり」で切り替えられるよう、`cmp.mt`(ミュートするトラック)を使う(既存の聞き比べ機構)。
- 新しい音源・新しい聞き比べ機構は作らない(OC-F を除く)。

- 実在の機材・メーカー・商品の評価や比較。
- 購入の推奨・値段の比較。
- 医学的な主張(「耳に良い」「健康に良い」など)。
- 実際の電気工事・配線の手順(安全上、書かない)。
- 「効く/効かない」の断定。仕分けと確かめ方だけを扱う。
- 実際の機器の音の再現(アプリ内の体験は、すべて近似)。
