対象アプリ: シンセ道場 v15.9(`synth-dojo-v15_9-mr6d.zip`)
位置づけ: `docs/SPEC_MR_mastering_course.md`(以下「機能仕様」)の **MR-5(レッスン本文)** を、先に進んでしまった MR-6 の機能を含めて組み直した仕様書。機能仕様には §4〜§9 が無いので、**レッスンの設計はこの文書を正とする**。

## 0. 現状(機能は出揃っている)

MR-1〜MR-4・MR-6a〜d が実装済みで、**足りないのはレッスンだけ**。レッスンで使える機能は次のとおり。

| 区分 | 使える機能(ID) | 画面 | 実装 |
|---|---|---|---|
| リミッター | `limGain` `limCeil` `limRel` `limLook` `limTP`、LIM GR | FX「LIMITER」・MIX メーター | MR-1/2/4 |
| 出口コンプ | `outTrim` `mc*`(7つ) | FX「OUT COMP」 | MR-1 |
| クリッパー | `clipOn` `clipThr` `clipShape` | FX「CLIPPER」 | MR-4 |
| トーン・幅 | `mq*`(4バンド+HPF・STEREO/MID/SIDE)・`monoBelow` | FX「MASTER EQ」 | MR-3 |
| 計測 | LUFS M/S/I・TP・PLR・**PSR・CREST**・相関・バランス・モノ差 | MIX「LUFS」 | MR-2 |
| 計測の表示 | LUFS 時間推移・SPEC(1/3oct)・GONIO・帯域相関 | MIX の METER | MR-2/3 |
| 比較 | MASTER BYPASS(音量を揃える)・PRESET(標準/配信向け/放送向け/押し込み+U1〜U3)・再生側の調整 | MIX の計測行 | MR-2/4 |
| 入出力 | REC→WAV(16/24 bit・ディザ)・ロッシー風モニター・MASTERING(2ミックス取り込み)・REF(自分のリファレンス) | MIX | MR-6a〜d |

測定目標 `mt` で使える指標: `lufsM` `lufsS` `lufsI` `tp` `plr` `corr` `bal` `mdiff` `psr` `crest` `grLim`(マスターのみ)。

## 1. 方針

1. **1本1テーマ**。1本で覚えることは1つ。手順は 3〜5 ステップ。
2. **音量を揃えて聞き比べる**を全レッスンの作法にする(`cmp` の音量差は 1 dB 以内。BYPASS・REF の自動揃えを使う回は例外で、その旨を本文に書く)。
3. **マスターで直すのは最後の少しだけ**。ミックスの問題は MX・XB・XE に戻す(機能仕様 §1.1)。
4. 本文は 150 字以内・年号なし・外部の規格名/サービス名/機材名なし。用語は `【用語名】`。目標値は `loud.js` のプリセット(`broadcast` -23・`stream` -14・TP -1)を参照し、数字を2か所に書かない。
5. **近似・限界は本文に書く**: ロッシー風は高域を削るだけの近似。TRUE PEAK は「天井を完全に守る」とは書かない(高域の多い音で最大 1.3 dB ほど超えうる)。メーターの TP は山をやや低く見積もる。
6. **権利**: MASTERING・REF の回は「自分が権利を持つ曲だけ」「メモリだけ・保存しない」を必ず本文に入れる。
7. 判定は聞き比べ(耳)→数値(`mt`)の順。数値だけで合格にしない回(mr01・mr22)は `quiz` で確認。
8. 脅さない・急がせない。音量は小さめで、こまめに休む(`COL` の定型文を踏襲)。

## 3. レッスン仕様

表記: **学ぶこと** / **使う** / **流れ** / **合格** / **注意**。`mt` は測定目標(`rng` は範囲・`hold` は秒)。

### 3.1 初級(lv:1)

**mr01 マスタリングとは**〔read〕
- 学ぶこと: 仕上げの3つの目的(バランス・音圧とピーク・環境で崩れないか)と「最後の少しだけ」。
- 流れ: ①完成したミックスの最後の工程 ②3つの目的 ③直すなら MX・XB に戻る ④このコースの道具の地図(FX の OUT COMP / MASTER EQ / CLIPPER / LIMITER、MIX の計測)。
- 合格: `quiz` 2問(目的はどれか・マスターで直さないものはどれか)。
- 用語: マスタリング(新)。

**mr02 音量を揃えて聞き比べる**〔recipe〕
- 学ぶこと: 大きい方が良く聞こえる。比べるときは音量を揃える。
- 使う: MASTER BYPASS(処理あり/なし)。
- 流れ: ①わざと音量差をつけて聞き比べ(`quiz`)②BYPASS で「処理あり/なし」を揃って聞く ③差が音量でなく音色だと気づく。
- 合格: `quiz`。BYPASS を ON/OFF した記録(UI 操作の確認)。
- 注意: BYPASS は MIX を離れると OFF に戻る旨を書く。lm11 の続き。

**mr03 余白をつくる(OUT TRIM とヘッドルーム)**〔recipe〕
- 学ぶこと: 入れる音が大きすぎるとリミッターが働きすぎる。まず入口の大きさを整える。
- 使う: `outTrim`、LIM GR、TP。
- 流れ: ①OUT TRIM を +6 dB にして GR が増えるのを見る ②0 に戻す ③-3 dB にして余裕を見る。
- 合格: `mt`: `grLim` rng 0〜1(働きすぎていない)hold 3。
- 注意: xb05(ヘッドルーム)の続き。

**mr04 目標の大きさにする(LUFS)**〔recipe〕
- 学ぶこと: 配信向けの目安は -14 LUFS。LUFS-S を見ながら大きさを合わせる。
- 使う: LUFS 画面の「目標」・`limGain`。
- 流れ: ①放送向けと配信向けの違い(9 LU)②目標を選ぶ ③`limGain` で S を目標に入れる。
- 合格: `mt`: `lufsS` rng [-15,-13] hold 3。
- 注意: 数字は目安・変わりうる(lm06 の文を踏襲)。lm06 との重なりは「MR は limGain で上げる」点で区別。

**mr05 天井(CEILING)を決める**〔recipe〕
- 学ぶこと: 天井=これ以上は出さない上限。変換や再生の余裕のため -1 付近にする。
- 使う: `limCeil`(-6〜-0.1)・TP。
- 流れ: ①天井 -0.1 と -3 を聞き比べ(音量は揃える)②TP が天井付近で止まるのを見る ③-1 に決める。
- 合格: `mt`: `tp` rng [-1.6,-0.6] hold 3(近似メーター。誤差を本文に書く)。
- 用語: 天井(新)・トゥルーピーク(`lm_tp` を使う)。

**mr06 押し込み(GAIN)と音圧の入口**〔recipe〕
- 学ぶこと: 音圧は「リミッターにどれだけ入れるか」で決まる。入れすぎるとつぶれる。
- 使う: `limGain`(0〜+18)・LIM GR。
- 流れ: ①GAIN 0 / +4 / +10 を音量を揃えず聞く(`quiz`:大きく聞こえるのは)②揃えて聞く(つぶれ・窮屈)③GR が 1〜3 dB の控えめな設定に戻す。
- 合格: `mt`: `grLim` rng [1,3] hold 3。
- 用語: 押し込み(新)。ms03 の続き。

### 3.2 中級(lv:2)

**mr07 出口のコンプ(見えなかった固定コンプ)**〔recipe〕
- 学ぶこと: 出口には元からコンプが入っている。FX の COMP とは別物。
- 使う: `mcOn mcThr mcRatio mcAtk mcRel mcKnee mcMake`。
- 流れ: ①OFF/ON 聞き比べ ②THRESH・RATIO を動かす ③「まとまり」と「つぶれ」の境目。
- 合格: `f` つまみ目標(`mcThr` -14〜-8・`mcRatio` 2〜4)+`quiz`。
- 注意: ms01 の「マスターのコンプ」=FX の COMP と、出口コンプを呼び分ける(機能仕様 D-5)。出口コンプの GR は `mt` 指標に無い(§7 O-2)。

**mr08 リリースとポンピング**〔recipe〕
- 学ぶこと: リリースが短いと歪み・息つぎ、長いと戻りが遅れる。
- 使う: `limRel`(10〜1000)。
- 流れ: ①10 ms ②80 ms ③400 ms を同じ音量で聞き比べ ④曲に合う値を選ぶ。
- 合格: `quiz`+`f`: `limRel` 40〜200。
- 注意: 低域の多い曲で効果が分かる素材を使う(キックの強い土台)。

**mr09 マスター EQ は「広く・小さく」**〔recipe〕
- 学ぶこと: 仕上げの EQ は ±1〜2 dB。大きく動かしたらミックスへ戻る。
- 使う: LOW SHELF・HIGH SHELF・`mqOn`(A/B。音量は変わらない)。
- 流れ: ①LOW SHELF +1.5 ②HIGH SHELF +1.5 ③ON/OFF で A/B ④±6 を超えたら戻る理由。
- 合格: `f`: `mq*` ゲイン |g| ≤ 2(多用ガード)+`quiz`。

**mr10 低域を整える(HPF とスペクトラム)**〔recipe〕
- 学ぶこと: 聞こえない超低域を切り、濁りを減らす。
- 使う: HPF(20Hz=OFF)・SPEC(目安の傾き線)。
- 流れ: ①SPEC で低域の山を見る ②HPF を 30 Hz 付近に ③聞き比べ(キック・ベースが痩せないか)。
- 合格: `f`: HPF 25〜40 Hz。
- 注意: 小スピーカー(ms04)では聞こえない帯域の話にとどめる。

**mr11 中高域の補正(BELL×2)**〔recipe〕
- 学ぶこと: 刺さり(高め)・こもり(中域)を 2 点で小さく直す。
- 使う: BELL×2(周波数・ゲイン・Q)。
- 流れ: ①問題つきミックス(刺さり)②BELL を動かして探す ③-1.5 dB 程度で止める。
- 合格: `f`: 対象帯の BELL ゲイン -3〜-0.5。
- 注意: 探すときは大きく動かして見つけ、直す量は小さく。

**mr12 ステレオ幅と相関(GONIO)**〔recipe〕
- 学ぶこと: 広いほど良いわけではない。相関が低いとモノで消える。
- 使う: GONIO・帯域相関・`corr` `mdiff`。
- 流れ: ①GONIO の見方(縦=中央・横=サイド)②広げすぎのミックスを見る ③PAN・幅を戻して相関を上げる。
- 合格: `mt`: `corr` rng [0.3,1] hold 3。
- 注意: xs05・xs06 の続き。

**mr13 低域のモノ化(MONO BELOW)**〔recipe〕
- 学ぶこと: 低域は中央に。サイドの低域を切ると小さな機器でも崩れにくい。
- 使う: `monoBelow`(0=OFF〜300 Hz)・MONO モニター。
- 流れ: ①低域がサイドに広がった素材 ②MONO BELOW を 120 Hz 付近に ③MONO モニターで確認(確認後は OFF に戻す)。
- 合格: `f`: `monoBelow` 80〜200 +低域の帯域相関(`mt` に無い場合は `quiz`)。
- 注意: ms04 の続き。

**mr14 音量の時間推移(曲のどこが大きいか)**〔read+recipe〕
- 学ぶこと: LUFS-S のグラフで、サビが大きすぎる・静かな所が小さすぎる、を見る。
- 使う: LUFS の時間推移グラフ・RESET。
- 流れ: ①1周流して推移を見る ②大きい所・小さい所 ③全体を整える方向(トラックの量から)。
- 合格: `quiz`(グラフから読み取る)。
- 注意: 曲の最大 6 分まで。グラフが出るまで少し待つ。

**mr15 トゥルーピーク(TRUE PEAK)**〔recipe〕
- 学ぶこと: サンプルの間の山まで見ると、変換後の割れを減らせる。
- 使う: `limTP`(既定 OFF)・TP。
- 流れ: ①OFF/ON で TP を見る(高域の多い素材)②聞き比べ ③ON にして天井を決め直す。
- 合格: `mt`: `tp` rng [-1.6,-0.6] hold 3。
- 注意: **「完全に守る」と書かない**(高域の多い音で最大 1.3 dB ほど超えうる)。メーターの TP が山を低く見積もる点も書く。lm07 の続き。

### 3.3 上級(lv:3)

**mr16 M/S EQ(中央とサイドを別々に)**〔recipe〕
- 学ぶこと: 中央は締め、サイドは少し広げる。
- 使う: `mqMode`(STEREO/MID/SIDE)。
- 流れ: ①MID で低域を整える ②SIDE の高域を少し持ち上げる ③STEREO と聞き比べ。
- 合格: `f`: `mqMode` の切替操作+`mt`: `corr` rng [0.4,1]。
- 用語: M/S(新)。

**mr17 クリッパーとリミッターの分担**〔recipe〕
- 学ぶこと: 山を先にクリッパーで落とすと、リミッターの働きが減る。
- 使う: `clipOn clipThr clipShape`・LIM GR。
- 流れ: ①クリッパー OFF で GR を見る ②SOFT で -3 dB ③HARD と SOFT を聞き比べ ④落とした GR を確認。
- 合格: `mt`: `grLim` rng [0,3]+`quiz`。
- 注意: 削りすぎはひずみ(ms03 の続き)。用語: クリッパー(新)。

**mr18 先読み(LOOKAHEAD)**〔recipe〕
- 学ぶこと: 先読みが短いとひずみやすく、長いとアタックがなまる。
- 使う: `limLook`(1/2/5 ms)。
- 流れ: ①1 / 2 / 5 ms を同じ音量で聞き比べ ②キック・ハットで違いを聴く。
- 合格: `quiz`。
- 注意: 差はわずか。「違いが分からなくても良い」と明記。用語: ルックアヘッド(新)。

**mr19 音圧の代償を数値で見る(PSR・CREST)**〔recipe〕
- 学ぶこと: 押し込むと PSR・CREST が下がる。ダイナミクスの残り量を数値で見る。
- 使う: `psr` `crest`・`limGain`。
- 流れ: ①GAIN 0 の PSR/CREST を覚える ②GAIN を上げて下がり方を見る ③下げすぎない目安に戻す。
- 合格: `mt`: `psr` rng [8,14]・`crest` rng [8,14] hold 3。
- 用語: PSR(新)・ダイナミックレンジ(新)。lm08(PLR)の続き。

**mr20 再生側のラウドネス調整を体験する**〔recipe〕
- 学ぶこと: 大きく作っても、配信先で下げられる。つぶした音は戻らない。
- 使う: 「再生側: 調整して聴く」(`playGain`)・目標の切替。
- 流れ: ①-8 LUFS 級と -14 LUFS 級を作る ②再生側で揃えられる ③つぶした方が結局小さく痩せる。
- 合格: `quiz`。
- 注意: -11・-19 は聴く側の設定で作る側の目標ではない(lm06 と同じ書き方)。用語: ノーマライズ(新)。

**mr21 目的別に仕上げる(PRESET)**〔recipe〕
- 学ぶこと: 配信向け・放送向け・押し込み、目的で設定の初期値が違う。
- 使う: PRESET(標準・配信向け・放送向け・押し込み・U1〜U3)。
- 流れ: ①プリセットを呼び出す ②自分の曲に合わせて微調整 ③U1 に保存。
- 合格: `mt`: `lufsS` 目標帯+`tp` 上限+`psr` 下限の**複合**(3つ同時)。
- 注意: プリセットの数値は案。「そのまま使わず、聞いて直す」前提。

**mr22 マスターのチェックリスト(環境で崩れないか)**〔recipe〕
- 学ぶこと: MONO・小スピーカー・小音量・BYPASS の4点で最終確認。
- 使う: モニター(MONO・小SP)・MASTER BYPASS。
- 流れ: ①MONO ②小SP ③小音量 ④BYPASS で A/B。確認後は必ず OFF に戻す。
- 合格: `quiz`(崩れ方から原因を当てる)。
- 注意: ms06 のマスター版。モニターは起動時 OFF・確認後に戻す。

**mr23 お手本(アプリ内)と比べる**〔recipe〕
- 学ぶこと: リファレンスは「同じ音量で」「違いを1つずつ」比べる。
- 使う: アプリ内お手本(`refmix`・mx13)・SPEC・LUFS。
- 流れ: ①お手本と自分の LUFS を揃える ②SPEC で低域・高域の差を見る ③差を1つだけ直す。
- 合格: `quiz`+`mt`: `lufsS` をお手本に合わせる。
- 注意: xb06・mx13 の続き。自分の曲での比べ方は mr27 で扱うと予告。

**mr24 総合課題: 仕上がっていないミックスを仕上げる**〔diag〕
- 学ぶこと: ここまでの判断を組み合わせて、制限内で仕上げる。
- 使う: すべて。
- 流れ: 専用ミックス `SD.MR_RAW`(音が小さい・低域が濁る・幅が広い・天井が高すぎ)→ 診断 → 直す。ヒントは段階表示。
- 合格: `mt` 複合: `lufsS`・`tp`・`corr`・`psr` を同時に満たす hold 5+`quiz`。
- 注意: 「正解は1つではない」と書く。保存は `kit`(仕上げた設定)。

### 3.4 発展(lv:3・MR-6 の機能。MR-6 のレッスン本文はここ)

**mr25 書き出しとディザ(REC)**〔recipe〕
- 学ぶこと: 16 bit にするときの量子化ノイズを、ディザで目立たなくする。
- 使う: REC(16/24 bit・DITHER)・`SD.WAV`。
- 流れ: ①BYPASS OFF を確認 ②REC → 流す → STOP ③16 bit と 24 bit の違い ④DITHER の ON/OFF(非常に小さい音で効果を聞く)。
- 合格: `quiz`+REC 操作の確認。
- 注意: リアルタイム録音(曲を流した時間がかかる)・最大 180 秒・ノイズシェイピングなし・MIX を離れると録音は捨てる。保存先は実機で未確認(§7)。用語: ディザ(新)。

**mr26 ロッシー風で確かめる(近似)**〔read+recipe〕
- 学ぶこと: 圧縮された再生で、高域が減ったときの聞こえ方を確かめる。
- 使う: MON の「ロッシー風 中/強」(約 16 kHz・約 11 kHz のローパス)。
- 流れ: ①OFF/中/強 ②MONO・小SP と併用 ③確認後は OFF に戻す。
- 注意: **近似であると本文に書く**。高域を削るだけで、実際の圧縮とは違う。プリエコー・水の中のような音・圧縮後の TP 増加は再現しない(その分は天井の余裕で見る)。

**mr27 自分の曲を仕上げる(MASTERING と REF)**〔recipe〕
- 学ぶこと: 自分が権利を持つ曲を取り込み、マスター段で仕上げ、好きな曲(REF)と音量を揃えて比べる。
- 使う: MASTERING(300 秒・40 MB)・REF(180 秒・40 MB・音量を揃える)・A/B。
- 流れ: ①MASTERING に自分の曲を読み込む ②曲のトラックを止める ③REF を読み込み、B で聞く ④A/B と LUFS の差を見て、差を1つだけ直す。
- 注意(必須): **自分が権利を持つ曲だけ**を使う・メモリだけに置き保存しない(アプリを閉じると消える)・長い曲は切り捨て・REF は基準であり正解ではない。REF はマスター段を通さない。
